Sources and verification

This is an independent educational edition of Predictive Modelling with Applications: Supervised and Unsupervised Learning, taught by Prof. Sayantee Jana at IIT Hyderabad. The supplied playlist contains the teaching recordings and a separate course introduction. IIT Madras coordinates NPTEL; the uploader’s name does not change the teaching institution.

Source coverage and authored additions

The source map preserves original recording titles, upload positions, durations, and verified official teaching order. Per-chapter records identify full transcript reading. Captions can misrecognize equations, code, and names. Selected frames are used to resolve specific ambiguities; they do not certify every slide or spoken statement.

Derivations, examples, computations, corrections, and research extensions are original teaching additions unless explicitly attributed. A section timestamp points to a related discussion, not to the origin of every equation in that section. Raw downloaded media, complete captions, and internal acquisition logs remain private and are excluded from the portable reader.

What the checks establish

Content inventory, conversion evidence, and the chapter metadata record distinct aspects of production. Independent AI reviews examine mathematics and pedagogy. Program execution checks finite calculations on the recorded environment. Browser checks examine rendering and controls. A source-free export check examines portability. None is a substitute for the others; none constitutes human expert certification, formal proof verification, or a comprehensive audiovisual audit.

The edition contains 18 chapters covering all 39 teaching recordings, 108 worked solutions, and 18 Python laboratories. Two independent AI review rounds are bound to each current chapter-body digest. Detailed execution and link checks, offline desktop/mobile checks, and mathematical-markup checks remain available for inspection.

Local use and rebuilding

Open index.html in a browser. The reader, search, mathematical rendering, and solution controls use bundled assets. Source videos and external references need an internet connection. Use the print control to produce a chapter PDF with expanded solutions.

Install the dependencies in requirements.txt in a Python environment. The version lock records the verified environment. Run python tools/build_book.py to rebuild the reader, and python tools/check_book.py for static and execution checks. Run python tools/check_reader.py for browser checks. The builder requires authored chapter bodies and public metadata, not private recordings or transcripts.
