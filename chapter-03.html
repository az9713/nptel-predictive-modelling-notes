3.1 Common variation is a model, not a discovered cause

A group of bank-stock returns may move together while another group of energy-stock returns follows a different pattern. A compact representation can describe those shared movements. Calling two extracted coordinates “bank” and “energy” may help interpretation, but the names do not prove that two independently existing economic causes have been identified. Factor analysis makes a particular covariance model explicit; its fit and its interpretation are separate questions.

For one observational unit, let $\mathbf{x}\in\mathbb{R}^d$ be a real feature vector and let $\boldsymbol\mu=\mathbb{E}[\mathbf{x}]$ be its mean. An orthogonal common-factor model writes

$$\mathbf{x}=\boldsymbol\mu+\boldsymbol\Lambda\mathbf{f}+\mathbf{u}. \tag{3.1}$$

The vector $\mathbf{f}\in\mathbb{R}^k$ contains $k<d$ latent common factors. The loading matrix $\boldsymbol\Lambda\in\mathbb{R}^{d\times k}$ relates them to observed features. The vector $\mathbf{u}\in\mathbb{R}^d$ contains feature-specific contributions. The model assumes $\mathbb{E}[\mathbf{f}]=\mathbf{0}$, $\mathbb{E}[\mathbf{u}]=\mathbf{0}$, $\operatorname{Cov}(\mathbf{f})=\mathbf{I}_k$, $\operatorname{Cov}(\mathbf{u})=\boldsymbol\Psi$, and $\operatorname{Cov}(\mathbf{f},\mathbf{u})=\mathbf{0}$. The uniqueness matrix $\boldsymbol\Psi$ is diagonal with nonnegative entries $\psi_1,\ldots,\psi_d$.

“Orthogonal” here means uncorrelated unit-variance factors. It does not require their statistical independence. A diagonal uniqueness matrix also means uncorrelated specific contributions, rather than independence without an additional distributional assumption. Centering observed columns does not prove any of these latent covariance restrictions. They are modeling assumptions that must be assessed through their observable implications and the scientific context.

The model is not a partition of variables into disjoint factor groups. A measured feature can load on several common factors. Nor does the loading matrix guarantee that each resulting direction has a unique verbal interpretation. Exploratory factor analysis estimates a covariance representation with relatively few common coordinates. Confirmatory factor analysis adds specified restrictions from a proposed structure; that broader model-testing topic is outside the present course.

Source discussion: observed variables as functions of latent factors, 12:44 and factor-model assumptions, 0:16. The illustrative source claims about academic and athletic performance are not needed to establish the mathematics and are not treated as verified population facts.

3.2 The covariance decomposition and communalities

Proposition 3.1 — observable covariance. Under the assumptions of (3.1), the feature covariance matrix is $$\boldsymbol\Sigma=\operatorname{Cov}(\mathbf{x})=\boldsymbol\Lambda\boldsymbol\Lambda^{\mathsf T}+\boldsymbol\Psi. \tag{3.2}$$ The feature–factor covariance is $\operatorname{Cov}(\mathbf{x},\mathbf{f})=\boldsymbol\Lambda$.

Substitute $\mathbf{x}-\boldsymbol\mu=\boldsymbol\Lambda\mathbf{f}+\mathbf{u}$ into $\mathbb{E}[(\mathbf{x}-\boldsymbol\mu)(\mathbf{x}-\boldsymbol\mu)^{\mathsf T}]$. Expanding gives $\boldsymbol\Lambda\mathbb{E}[\mathbf{f}\mathbf{f}^{\mathsf T}]\boldsymbol\Lambda^{\mathsf T}$, two cross terms, and $\mathbb{E}[\mathbf{u}\mathbf{u}^{\mathsf T}]$. Unit factor covariance gives the first term $\boldsymbol\Lambda\boldsymbol\Lambda^{\mathsf T}$. Zero factor–specific covariance eliminates both cross terms, and the final term is $\boldsymbol\Psi$. Similarly, $\mathbb{E}[(\boldsymbol\Lambda\mathbf{f}+\mathbf{u})\mathbf{f}^{\mathsf T}]=\boldsymbol\Lambda$. ∎

For feature $j$, the communality is $h_j^2=\sum_{a=1}^k\Lambda_{ja}^2$, its variance contributed by common factors. Its total variance is $\Sigma_{jj}=h_j^2+\psi_j$. If features have unit variance, the decomposition becomes $1=h_j^2+\psi_j$. A loading equals a feature–factor covariance under this model. It equals a correlation only when that feature also has unit variance, since the factor already does.

For different features $j$ and $\ell$, the diagonal uniqueness assumption gives $\Sigma_{j\ell}=\sum_a\Lambda_{ja}\Lambda_{\ell a}$. Common factors explain the off-diagonal relationships. A positive uniqueness allows a variable to have substantial variation that is not shared with the others. If a fitted unit-variance model produces $h_j^2>1$, its implied uniqueness is negative. Such a Heywood case is not a permissible variance decomposition and requires investigation rather than literal interpretation.

This distinguishes common-factor analysis from PCA. PCA forms linear combinations of observed variables and optimizes total projected variance or reconstruction error. A low-rank PCA loading product approximates the whole observed covariance, including its diagonal. A common-factor model additionally fits a diagonal uniqueness term, so the common component need not explain every marginal variance. Taking a full spectral square root of a covariance matrix with $d$ directions gives an exact product with zero uniqueness, but that construction alone does not establish a low-dimensional common-factor explanation.

A factor count must also respect identifiability. An unrestricted $d\times k$ loading matrix contains $dk$ entries and the diagonal uniqueness adds $d$, but orthogonal rotations contribute $k(k-1)/2$ equivalent coordinates. A necessary parameter-count condition is $dk+d-k(k-1)/2\leq d(d+1)/2$. This count is not a sufficient identifiability theorem. It does expose why attempting many factors from a small covariance matrix can leave insufficient independent information.

Source derivation: the covariance expansion, 3:34 and communalities and specific variances, 9:39. The parameter count is an explicit dimensional check, not a claim of unique factor identification.

3.3 Rotation changes interpretation without changing fitted common covariance

Proposition 3.2 — rotational nonidentification. Let $\mathbf{Q}$ be any orthogonal $k\times k$ matrix. Set $\boldsymbol\Lambda_* =\boldsymbol\Lambda\mathbf{Q}$ and $\mathbf{f}_*=\mathbf{Q}^{\mathsf T}\mathbf{f}$. These replacements preserve the common term in (3.1), the identity factor covariance, and the covariance decomposition (3.2).

Orthogonality gives $\mathbf{Q}\mathbf{Q}^{\mathsf T}=\mathbf{I}$. Therefore $\boldsymbol\Lambda_*\mathbf{f}_*=\boldsymbol\Lambda\mathbf{f}$ and $\boldsymbol\Lambda_*\boldsymbol\Lambda_*^{\mathsf T}=\boldsymbol\Lambda\boldsymbol\Lambda^{\mathsf T}$. The factor covariance becomes $\mathbf{Q}^{\mathsf T}\mathbf{I}\mathbf{Q}=\mathbf{I}$. The remaining zero means and cross covariances are preserved by the same linear transformations. ∎

Each row of the loading matrix retains its squared length under this rotation, so each communality stays fixed. Column sums of squared loadings may change. Thus the share assigned to a named factor can change even when the fitted common covariance is identical. A variable can move from a mixture of two factors toward a larger loading on one rotated factor, making a compact verbal description easier.

Varimax is an orthogonal-rotation criterion that favors uneven squared loadings within columns: many relatively small loadings and a smaller set of relatively large ones. For a loading matrix $\mathbf{A}$, its criterion is proportional to $\sum_a[\sum_j A_{ja}^4-d^{-1}(\sum_j A_{ja}^2)^2]$. When Kaiser normalization is enabled, rows are first divided by their common-factor lengths for the rotation search, and restored afterward. The laboratory states that normalization explicitly and implements the corresponding singular-value-based orthogonal updates.

An oblique representation permits correlated factors with covariance $\boldsymbol\Phi$ instead of the identity. Its common covariance is $\boldsymbol\Lambda\boldsymbol\Phi\boldsymbol\Lambda^{\mathsf T}$. Dropping $\boldsymbol\Phi$ while retaining oblique pattern loadings would change the model. Orthogonal and oblique conventions must therefore remain visible when translating software output. The source stock code explicitly requests rotate="none" before rotate="varimax"; that first result is not a default oblimin fit.

Factor scores add another layer of inference. Even if the population parameters were known, the factors are unobserved because specific variation remains. Among linear predictors $\widehat{\mathbf{f}}=\mathbf{A}(\mathbf{x}-\boldsymbol\mu)$ with positive definite $\boldsymbol\Sigma$, expected squared prediction error is minimized at $\mathbf{A}_*=\boldsymbol\Lambda^{\mathsf T}\boldsymbol\Sigma^{-1}$. To see this, use $\operatorname{Cov}(\mathbf{x},\mathbf{f})=\boldsymbol\Lambda$ and expand the quadratic expectation. Completing the square gives

$$E\|\mathbf{f}-\mathbf{A}(\mathbf{x}-\boldsymbol\mu)\|^2=\operatorname{tr}(\mathbf{I}_k-\boldsymbol\Lambda^{\mathsf T}\boldsymbol\Sigma^{-1}\boldsymbol\Lambda)+\operatorname{tr}\!\left[(\mathbf{A}-\mathbf{A}_*)\boldsymbol\Sigma(\mathbf{A}-\mathbf{A}_*)^{\mathsf T}\right].$$

Positive definiteness makes the second term nonnegative, uniquely zero at $\mathbf{A}=\mathbf{A}_*$. The prediction-error covariance is $\mathbf{I}_k-\boldsymbol\Lambda^{\mathsf T}\boldsymbol\Sigma^{-1}\boldsymbol\Lambda$. The matrix need not vanish. A calculated score is therefore an estimate of a latent coordinate, not a direct measurement of that coordinate.

Source rotation argument and example: orthogonal invariance, 0:49 and stock-factor rotation, 12:20. Software normalization is checked against the R varimax documentation.

3.4 Principal-axis extraction and the meaning of convergence

The displayed R examples request fm="pa", meaning principal-axis extraction. This is not the default minimum-residual method, and it is not an instruction to compute ordinary principal components. For a correlation matrix $\mathbf{R}$, principal-axis extraction replaces the diagonal ones by provisional communalities while retaining the observed off-diagonal correlations. An eigendecomposition of that reduced matrix then estimates its common component.

One initialization uses squared multiple correlations. For invertible $\mathbf{R}$, the initial communality for variable $j$ is $1-1/(\mathbf{R}^{-1})_{jj}$. To interpret the expression, regress standardized variable $j$ linearly on the other standardized variables. The block-inverse identity gives residual variance $1/(\mathbf{R}^{-1})_{jj}$; subtracting from its unit total variance gives the variance fraction explained by that auxiliary regression.

At iteration $m$, let $\mathbf{R}^{(m)}$ have the observed off-diagonal entries and current communality estimates on its diagonal. Retain its largest $k$ positive eigenvalues $\eta_a$ and corresponding unit eigenvectors $\mathbf{v}_a$. Form provisional loadings $\Lambda_{ja}^{(m+1)}=v_{ja}\sqrt{\eta_a}$ and replace the diagonal with $\sum_a(\Lambda_{ja}^{(m+1)})^2$. Repeating the update seeks a fixed point of this diagonal-replacement construction. It does not supply a general guarantee that a statistically acceptable model will result.

The source package stops this principal-axis iteration when the absolute change in total communality falls below $0.001$, or when its default limit of 50 iterations is reached. The Python conversion implements those same choices. It also records iteration history so the two stopping reasons remain distinguishable. A program returning a loading matrix after the limit is reached is not evidence of convergence. Subsequent rotation cannot repair a failed variance decomposition because it preserves communalities.

Minimum-residual extraction instead optimizes a residual criterion, and Gaussian maximum-likelihood extraction uses a distributional likelihood. Their finite estimates, constraints, and numerical behavior differ. It is therefore inappropriate to replace a source principal-axis call with a library's default factor-analysis method solely because both functions return a loading matrix. The parallel-analysis calls in this recording do use a separate default one-factor minimum-residual calculation for their factor reference spectrum. The laboratory preserves that distinction.

Normality is not needed for the covariance identity or for running the algebraic principal-axis update. Normal-theory likelihood inference does require its distributional assumptions; interpreting a non-Gaussian quasi-likelihood fit would need a separate justification. There is no universal ordering under which one of these methods must always have smaller residuals or lower computational cost. Those comparisons depend on the criterion, the matrix, constraints, and convergence settings.

Displayed source commands and matrix inspected at 7:20. Extraction and stopping conventions checked in the primary psych implementation; the Python minimum-residual interface is documented by factor_analyzer.

3.5 Two converted examples, with a failed-fit warning preserved

The first displayed program uses ability.cov, a six-test covariance summary from 112 individuals. Dividing each covariance by the product of its two marginal standard deviations converts it to a correlation matrix. Python then reproduces the source's two-factor principal-axis extraction. It reaches the stated tolerance after 22 iterations. Its communalities range from approximately $0.202182$ to $0.910786$, and all six uniqueness estimates are positive. That numerical admissibility is necessary for interpreting a variance decomposition; it does not establish that the factors are unique psychological entities.

The stock example loads a CSV whose numerical part is already a five-by-five correlation matrix. Selected on-screen code and output supply all 25 entries, retained with the notebook data. The three bank variables are JPMorgan, Citibank, and Wells Fargo; the two energy variables are Shell and Exxon. The correlation between Shell and Exxon is $0.683$, while correlations between the two groups are smaller in this supplied matrix. Matrix recognition matters: treating these five rows as five independent original return observations and computing another correlation matrix would analyze a different object.

The source stock parallel-analysis call omits its original observation count. The R package recognizes a correlation matrix and falls back to an assumed count of 100. Python reproduces that assumption explicitly. It cannot determine the number of underlying trading observations from this matrix. Consequently, this simulated-null illustration is not a validated sampling analysis of the original returns. The ability example, in contrast, supplies its documented count of 112.

The displayed stock extraction reaches its default limit of 50 principal-axis iterations before satisfying the tolerance. The final total-communality change is approximately $0.00273909$, above $0.001$. Its Shell uniqueness is already near zero, approximately $0.004479$. Continuing the same update for 100 diagnostic iterations gives a negative Shell uniqueness, approximately $-0.199958$. Those additional iterations are an authored investigation of the failure, not a recommended factor fit.

This warning is reproduced in a fresh R run as well as in Python. The source method is convertible; its numerical model has a convergence problem. Both the unrotated and varimax loadings at the source's finite stopping point agree between the two implementations, up to sign and column permutation. Interpretable bank and energy loading patterns do not erase that failure. Rotation preserves the common covariance and therefore cannot convert the inadmissible continuation into a valid variance model.

These checks are recorded separately from the Monte Carlo null streams, which are not identical across languages.

Neither summary matrix contains the individual observations needed to calculate each person's or each time point's factor score. Score-weight matrices are computable, but inventing individual rows would create a new example. 3.6 What the model captures and what it misses

The common-factor model captures a low-rank explanation of shared second moments plus feature-specific variance. It does not automatically capture nonlinear dependence, identify causal mechanisms, or validate verbal factor names. A fit should be examined through residual correlations, nonnegative uniquenesses, sensitivity to factor count and extraction method, convergence, and consistency with the measurement design. A plausible rotation cannot substitute for those checks.

The source also discusses converting categorical features to indicator columns and weighting them by a category's frequency. Such a transformation is calculable, but its interpretation must be stated. For a binary indicator $B$ with probability $p$ of value one, the variance is $p(1-p)$ and its standard deviation is $\sqrt{p(1-p)}$. Dividing a centered indicator by $\sqrt{p}$, a weighting used in some categorical-data representations, is therefore not the same as ordinary unit-variance standardization. The two procedures optimize different geometries.

All indicators for one categorical variable sum to one, so their centered columns sum to zero. The resulting covariance is singular if all categories are retained. Although numerical covariance calculations are still possible, a continuous Gaussian-factor likelihood is not justified merely by writing category membership as zeros and ones. A latent-variable model for categorical observations or a dedicated mixed-data representation requires its own assumptions. These notes preserve the source's computational idea while separating it from a claim that ordinary continuous-data factor analysis has become automatically appropriate.

Factor analysis compresses relationships among variables. Clustering, developed next, assigns observations to groups under a dissimilarity. A group of variables sharing a factor is not the same object as a group of observations assigned a cluster. The distinction determines which rows or columns are being compared and which scientific question the method can answer.

Source scope and mixed-variable discussion: 16:48. The Bernoulli variance calculation and the singular-indicator warning specify the limits of that proposed preprocessing.

3.7 Exercises with worked solutions

  1. Centering is not a latent assumption. Does subtracting each observed feature's mean prove that the factors have identity covariance or that the specific contributions are uncorrelated with them?

    Worked solution

    No. Centering fixes observed first moments. Identity covariance and zero cross covariance concern second moments of unobserved components. For example, replacing a latent variable by twice itself changes its variance without changing its mean; the associated loading can be halved without changing the observed model. Factor scaling therefore needs an explicit convention. The zero cross-covariance restriction is another independent part of the model.

  2. A small covariance model. Let the rows of a two-factor loading matrix be $(0.8,0)$, $(0.6,0)$, and $(0,0.7)$, and let the diagonal uniquenesses be $0.36,0.64,0.51$. Calculate the implied covariance and identify which pair shares common variation.

    Worked solution

    The common covariance is the loading product. Its diagonal is $0.64,0.36,0.49$, and its only nonzero off-diagonal pair is $0.8\cdot0.6=0.48$. Adding the specified uniquenesses makes every total variance one. The first and second observed variables share the first common factor. The third loads only on the second. This example does not imply that real data must have disjoint factor groups; nonzero cross-loadings would mix them.

  3. Rotation audit. Given an orthogonal matrix $\mathbf{Q}$, prove that rotating a loading matrix preserves each communality. Explain why this also preserves a negative fitted uniqueness rather than fixing it.

    Worked solution

    For row $j$, its rotated squared length is $\boldsymbol\Lambda_j\mathbf{Q}\mathbf{Q}^{\mathsf T}\boldsymbol\Lambda_j^{\mathsf T}=\boldsymbol\Lambda_j\boldsymbol\Lambda_j^{\mathsf T}$. The uniqueness is the observed variance minus that common variance, so it is unchanged as well. Orthogonal rotation changes coordinates within an existing common subspace. It does not change the model's diagonal residual or repair an inadmissible variance estimate.

  4. Scores from a summary. A covariance matrix and factor count are available, but the original participant rows are absent. Which operations can still be converted from R to Python, and which further request cannot be fulfilled exactly?

    Worked solution

    Covariance standardization, extraction, rotation, residual-correlation calculation, and score-weight estimation depend on summary moments and can be computed. Null simulations also need an explicit observation count. Listing the actual participant scores requires each original observation vector, so that further request cannot be satisfied by the summary alone. Simulating observations with the same covariance would create a different dataset and must not be labeled as recovered participants.

  5. Reproduce and diagnose. Run the source stock principal-axis update with its default 50-iteration limit, and then inspect 100 iterations at a tighter tolerance. Does agreement with a fresh R implementation establish a valid fitted factor model?

    Worked solution

    The default result has total-communality change approximately $0.00273909$, so it has not reached $0.001$. After 100 diagnostic iterations, the Shell uniqueness is approximately $-0.199958$. The Python and fresh R finite-iteration results agree, showing that the translation preserves the source algorithm. The negative continuation demonstrates why implementation agreement is a different claim from model admissibility or convergence. Increasing an iteration limit without checking the variance decomposition is insufficient.

  6. Indicator scaling. Derive the variance of a binary indicator with success probability $p$. Explain why dividing its centered values by $\sqrt{p}$ does not generally give unit variance, and why keeping every centered category indicator creates linear dependence.

    Worked solution

    Because $B^2=B$, $\operatorname{Var}(B)=\mathbb{E}[B^2]-\mathbb{E}[B]^2=p-p^2=p(1-p)$. After division by $\sqrt{p}$, the variance is $1-p$, not one. Ordinary standardization divides by $\sqrt{p(1-p)}$ when $0<p<1$. For mutually exclusive exhaustive categories, their indicators sum to one on every row. Their column means also sum to one, so subtracting those means makes the centered columns sum to zero. That is an exact linear dependency, independent of software.

"""Principal-axis factor analysis and conversion of all source R examples."""

from pathlib import Path

import numpy as np
import pandas as pd
from factor_analyzer import FactorAnalyzer

from ch02 import varimax

DATA = Path(__file__).resolve().parent / "data"


def covariance_to_correlation(covariance):
    """Match stats::cov2cor for a positive-diagonal covariance matrix."""
    scales = np.sqrt(np.diag(covariance))
    return np.asarray(covariance) / np.outer(scales, scales)


def principal_axis(correlation, count=2, tolerance=0.001, max_iter=50):
    """psych fm='pa': SMC start; total-communality stopping rule."""
    matrix = np.asarray(correlation, dtype=float)
    communalities = 1 - 1 / np.diag(np.linalg.inv(matrix))
    reduced = matrix.copy()
    np.fill_diagonal(reduced, communalities)
    previous = communalities.sum()
    history = []
    for _ in range(max_iter):
        values, vectors = np.linalg.eigh(reduced)
        values, vectors = values[::-1], vectors[:, ::-1]
        if np.any(values[:count] < 0):
            raise ValueError(
                "A retained principal-axis eigenvalue is negative"
            )
        loadings = vectors[:, :count] * np.sqrt(values[:count])
        communalities = np.sum(loadings**2, axis=1)
        total = communalities.sum()
        history.append(total)
        difference = abs(total - previous)
        np.fill_diagonal(reduced, communalities)
        previous = total
        if difference <= tolerance:
            break
    for column in range(count):
        if loadings[:, column].sum() < 0:
            loadings[:, column] *= -1
    order = np.argsort(np.sum(loadings**2, axis=0))[::-1]
    return loadings[:, order], np.array(history)


def common_eigenvalues(correlation, use_smc=True):
    """One-factor MINRES reduced spectrum for parallel FA."""
    model = FactorAnalyzer(
        n_factors=1,
        rotation=None,
        method="minres",
        is_corr_matrix=True,
        use_smc=use_smc,
    )
    model.fit(correlation)
    reduced = np.asarray(correlation).copy()
    np.fill_diagonal(reduced, model.get_communalities())
    return np.linalg.eigvalsh(reduced)[::-1]


def parallel_both(correlation, observations, iterations=100, seed=2026):
    """Convert matrix-input fa.parallel(...,fa='both') with explicit n.obs."""
    matrix = np.asarray(correlation)
    rng = np.random.default_rng(seed)
    pc_null, fa_null = [], []
    for _ in range(iterations):
        sample = rng.normal(size=(observations, len(matrix)))
        null = np.corrcoef(sample, rowvar=False)
        pc_null.append(np.linalg.eigvalsh(null)[::-1])
        fa_null.append(common_eigenvalues(null, use_smc=False))
    return {
        "pc_actual": np.linalg.eigvalsh(matrix)[::-1],
        "fa_actual": common_eigenvalues(matrix),
        "pc_cutoff": np.quantile(pc_null, 0.95, axis=0),
        "fa_cutoff": np.quantile(fa_null, 0.95, axis=0),
    }

    print("Three-variable exercise covariance:")

    print("Ability correlation matrix (converted cov2cor):")

    results = {}

        )

    ability_parallel = parallel_both(ability, 112)
