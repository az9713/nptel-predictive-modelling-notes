Python laboratory

Each program implements the model developed in its chapter and checks a numerical consequence. Run programs from the course folder in the same Python environment used to install requirements.txt. Local CSV files make retained source datasets usable offline; generated datasets are labeled as teaching constructions.

For example, run python labs/ch01.py. The corresponding output link records a completed execution. Regenerate plots with the laboratory that creates them. Randomized comparisons state seeds and tolerances; a shared seed across programming languages does not imply a shared random stream.
