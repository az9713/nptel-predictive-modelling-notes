R examples converted to Python

All teaching code in this edition uses Python. The conversion ledger identifies source R demonstrations, their Python implementation, available input data, numerical checks, and unresolved differences.

What a faithful conversion preserves

A conversion preserves the statistical question, data rows, feature transformations, model matrix, estimator, test variant, and interpretation. It need not preserve incidental cluster numbers, eigenvector signs, or the layout of a printed table. Those representational differences are explained where they occur.

Defaults require explicit attention. Covariance and correlation PCA can answer different questions. Factor extraction and rotation affect the reported loadings. R’s two Ward variants require different conventions. Factor contrasts determine coefficient meanings. Logistic classifiers may apply a penalty by default, whereas a source generalized linear model may be unpenalized.

Conversion obstacles and reproduction limits

A missing original CSV can block exact numerical reproduction while leaving the algorithm fully convertible. Such an example includes a Python workflow and a specific explanation of the missing input; any substitute data are labeled. An implementation checked against a mathematical identity or visible source output is distinguished from a fresh execution of both R and Python.

Caption reading alone may not recover every on-screen argument or dataset value. Each unresolved example states the remaining gap. No silent replacement is counted as an exact source reproduction.

Every inventoried statistical method has a Python implementation. Exact lecture-number reproduction remains limited for the insurance example (original age/sex CSV unavailable), three Toyota fits (the precise 29-row subset and 20 training indices unavailable), and consumption versus expenditure (original local CSV unavailable). Reusable Python workflows and explicitly labeled constructed checks accompany these examples. The state-data Box–Cox and spread-level demonstrations run on the canonical data, but some original transformation and smoother options could not be recovered. Unshown random states and package-version differences are recorded separately.

The clustering laboratory includes direct Python ports of DIANA, clustlearn bisecting k-means, the 26 default NbClust indices, and Hartigan–Wong k-means with compatible R random-stream operations. Fresh R comparisons are scoped to the retained fixtures and options. Floating-point ties between restarts can still alter the winning restart or cluster numbering.
