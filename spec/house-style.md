# House style

- Write graduate textbook exposition in English. Define technical terms before
  use, show the steps carrying each derivation, and interpret the result.
- Use bold lower-case vectors and bold upper-case matrices. Use n observations,
  p slopes, and q = p + 1 regression coefficients when an intercept is included.
  X is the design matrix; centered feature data are Z. See plan/notation.md.
- State domains, rank conditions, sampling assumptions, and conditioning beside
  a claim. Separate definitions, deterministic proofs, distributional results,
  asymptotic approximations, numerical checks, and heuristics.
- Use prove for deductions and numerically check for executed finite examples.
  Call the course's examples and our constructions by their actual origin.
- Rerun every numerical example. Record actual stdout, versions, seeds, and
  tolerances. A claimed match between R and Python needs an actual comparison.
- Number results and equations by chapter and link cross-references. Verify
  external locators rather than inventing page numbers.
- Cite source discussions with video IDs and timestamps validated against the
  duration; these anchors do not attribute all authored additions to NPTEL.
- Use six exercises per chapter as a planning target, with complete verified
  solutions; select figures for a specific explanatory need.
- Dark HTML is the default. Reader controls and print output must remain usable.
- Use US prose spelling, while preserving the official title's Modelling.
- The first approved drafted section becomes the prose reference. None exists yet.
